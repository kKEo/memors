Check the connection

Make sure {{.Label}} sees the server before you rely on it.

In {{.Label}}

{{- if eq .Agent "claude-code"}}
Start claude in the project folder and type /mcp. {{.Name}} should be listed as connected. In a terminal, claude mcp list shows the same.
{{- else if eq .Agent "claude-desktop"}}
Start a new chat and open the tools menu of the message box. {{.Name}} should be listed with its tools. If it is missing, Settings › Developer shows the server and its error.
{{- else}}
Open your client's MCP or tools settings. {{.Name}} should be listed as connected, with tools such as search and read.
{{- end}}
{{- if ne .Agent "claude-desktop"}}

In the menu bar

Once the agent calls a tool, it appears under {{.KB}} in the MemoRS Tray menu, and {{.KB}} › Open Stats Window shows what it is doing.
{{- end}}

Not connected?

Check that {{.KB}} is running in the menu bar, and that the address is {{.URL}}.
{{- if eq .Auth "token"}}
A 401 error means the token is missing or out of date.
{{end}}
{{- else}}

Start using it

The agent can now search the {{.KB}} knowledge base and cite what it finds.

Chat with the knowledge base

{{- if eq .Agent "claude-code"}}
Type /mcp__{{.Name}}__ask, then your questions. Answers come only from the knowledge base, each claim with its memo:// source. Add a namespace to narrow the search: /mcp__{{.Name}}__ask <namespace>.
{{- else if eq .Agent "claude-desktop"}}
Click + under the message box, choose {{.Name}} › ask, then ask your questions. Answers come only from the knowledge base, each claim with its memo:// source.
{{- else}}
If your client shows MCP prompts, start with the ask prompt of {{.Name}}, then ask your questions. Answers come only from the knowledge base, each claim with its memo:// source.
{{- end}}
Or just ask in any chat: "Check {{.Name}}: how do we …?"

Optional: teach the agent

Add SKILL.md from the memors-mcp release to the agent's skills, or a line such as "Search {{.Name}} before answering questions about this project" to its instructions (CLAUDE.md for Claude Code). It then looks things up without being asked.
{{- end}}
